# E-Commerce Supply Chain Analytics & Delivery Performance

An end-to-end data analytics project focused on analyzing e-commerce supply chain operations, delivery performance, sales, profitability, and regional performance using SQL and Looker Studio.

## Project Overview

The goal of this project is to analyze e-commerce order and shipping data to identify delivery delays, evaluate shipping performance, and understand sales and profitability across different regions and product categories.

The project uses SQL for data analysis and Google Looker Studio for interactive dashboard development.

## Key Business Metrics

| KPI | Value |
|---|---:|
| Total Orders | 65,752 |
| Total Sales | 36.78M |
| Total Profit | 3.97M |
| Late Delivery Rate | 54.82% |
| Average Shipping Days | 3.5 |

## Dashboard Features

- **Delivery Status Analysis:** Analysis of Late, Early, and On-Time deliveries.
- **Shipping Mode Performance:** Comparison of late delivery rates across shipping modes.
- **Shipping Time Analysis:** Actual vs. scheduled shipping days.
- **Regional Performance:** Sales and profit analysis across different regions.
- **Product Category Analysis:** Comparison of sales and profitability by product category.
- **Interactive Filters:** Explore performance by Order Region, Customer Segment, and Shipping Mode.

## Key Business Insights

- Approximately 54.82% of orders were delivered late.
- First Class shipping had the highest late delivery rate among the shipping modes analyzed.
- Standard Class accounted for the highest order volume.
- Regional sales and profitability varied significantly.
- Product category performance showed differences in revenue and profit contribution.
